## Findings deferred (not in this batch — file follow-up plans if scope allows)

These are real but lower-leverage than the seven above; they were not
selected for the initial batch by the operator. Each is grounded in
`file:line` evidence already captured in the audit.

- **DuckDB `Promise.race` timeout does not cancel the query** —
  `packages/server/src/adapters/duckdb.ts:21-42`. Resource leak under
  sustained slow-query load; needs a DuckDB-side cancellation pattern.
- **Self-heal `lastSql` is `''` when the binder throws before returning** —
  `packages/agent/src/graph.ts:501,512,524-528`. Heal feedback then lacks
  the offending SQL context.
- **JWT stored in `localStorage`** — `packages/studio/src/auth.ts:7-77`.
  Standard SPA trade-off; ideal fix is server-issued httpOnly cookie.
- **No request body size limit on `/api/generate`** —
  `packages/server/src/app.ts:108-138`. Low-impact DoS vector.
- **Naive `extractJson` (first `{`, last `}`)** —
  `packages/agent/src/json.ts:2-7`. Brittle, masked by the heal path.
- **Duplicate seed-loading logic** —
  `packages/server/src/store/dashboards.ts:174-203` vs
  `packages/server/src/store/postgres.ts:46-71`.
- **Duplicate `workspaceRoot` / `loadDotEnv`** —
  `packages/alpona-cli/src/cli.ts:40-52,100-109` vs
  `packages/server/src/env.ts:52-73`.
- **BM25 retrieval is O(terms × docs²)** —
  `packages/agent/src/retrieval/index.ts:65-78`. Negligible today,
  flares at >1k tables.
- **HS256 path skips issuer check unless `OIDC_ISSUER` set** —
  `packages/server/src/auth/middleware.ts:97-127`. Mitigated by compose
  default but worth documenting.
- **`/api/generate` is not rate-limited** — `packages/server/src/app.ts:108-138`.
  More expensive than `/api/query`; better DoS target. Touched on in
  plan 004's maintenance notes.
- **Phase 7 video pipeline** — `videos/tests/demo.spec.ts` (Playwright)
  exists; `setup.tape`, assembly script, and CI integration missing. Big
  plan, not the right shape for this batch.
