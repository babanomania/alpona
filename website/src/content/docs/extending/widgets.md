---
title: Adding a widget
description: Registry entries the binder and composer trust.
sidebar: { order: 2 }
---

A widget is a registry entry: a zod props schema, a `resultShape` contract
(which SQL columns map onto which visual roles), sizing rules, and agent hints
that teach the binder when and how to use it. The binder can only produce what
the registry can validate. See the [widget registry](/reference/widgets).
