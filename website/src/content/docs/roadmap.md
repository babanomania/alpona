title: Roadmap
description: Where Alpona is and where it's headed.
---

**Shipped**

- Schema-driven generative engine: classify → plan → bind → compose → copy.
- Ask mode with pin-as-widget; conversational refine via JSON Patch.
- Guardrails: AST gate, read-only role, parameterized binding, self-heal.
- Pluggable auth (none / apikey / OIDC) and Supabase deploy mode with RLS.
- The `alpona` CLI: init wizard, connect, users, migrate/seed/marts/dictionary.
- Three dataset packs and a starter-dashboard gallery that covers every layout
  and widget — for bundled packs and bring-your-own data alike.

**Next**

- More dataset packs and adapters.
- Regenerable demo videos (Playwright + VHS) embedded in these docs.
- Deeper catalog and conversation-rail tooling.
